## Project Description

This project recreates a pre-1990 Urdu newspaper front page using only HTML, as required in the assignment. The selected newspaper is The Siasat Daily (1967 edition), which reported the passing of the last Nizam of Hyderabad.

The layout was developed using semantic HTML5 elements and a structured table-based column grid to closely resemble the traditional multi-column newspaper format. Only inline CSS styling was used, and no external CSS or JavaScript was included.

---

## Features Implemented

- Proper HTML5 document structure with `<!DOCTYPE html>`
- Semantic HTML5 tags:
  - `<header>`
  - `<section>`
  - `<article>`
  - `<aside>`
  - `<footer>`
- Multi-column newspaper layout using `<table>`
- Nested tables to replicate complex column structure
- Proper heading hierarchy (`<h1>` to `<h4>`)
- Multiple images with appropriate `alt` attributes
- Inline CSS styling (no external CSS files used)
- Structured masthead including volume number, date, and price
- Clearly organized content sections such as:
  - Main headline
  - Life sketch article
  - Doctor’s bulletin
  - Procession details
  - City news
  - Royal family section
- Clean indentation and readable formatting
